# Project report outline (BCA)

1. **Introduction** - problem statement, objectives, scope
2. **Literature / existing systems** - resume screeners and skill-gap tools; their limits (opaque scores)
3. **System analysis** - requirements (functional and non-functional), feasibility, users
4. **System design** - architecture diagram (`docs/ARCHITECTURE.md`), data flow, taxonomy and data files, API design
5. **Implementation** - technologies (Python, scikit-learn, FastAPI, Streamlit, Docker), module descriptions, key algorithms (alias matching, implication closure, OR groups, topological ordering)
6. **Testing** - unit tests, regression benchmark, CI (`tests/`, `.github/workflows/ci.yml`)
7. **Evaluation** - dataset, metrics, baselines, ablation, results and limitations (`docs/EVALUATION.md`)
8. **Screenshots** - CLI report, Streamlit app, API docs page (`/docs`) - capture these after running the app
9. **Conclusion and future work** - larger taxonomy, NER/LLM extraction, experience matching, real labelled data
10. **References and appendices** - taxonomy sample, source code listing, user manual
